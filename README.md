# נקי! מונה גמילה

אפליקציית ווב (HTML/CSS/JS בקובץ אחד) שסופרת כמה זמן אתה נקי, כמה כסף חסכת ומה קורה בגוף.

- מעקב אחרי כמה התמכרויות במקביל: סיגריות, גראס (10 גרם ב-300 ₪), קריסטל מת׳ (גרם ב-400 ₪), וייפ, אלכוהול, או משהו אחר
- שעון חי, כסף שנחסך, "חיים שהרווחת" לסיגריות (כ-20 דקות לסיגריה)
- נקי-צ׳אן: דמות אנימה מקורית שמשנה הבעות ומעודדת
- מה אפשר לקנות בכסף, אבני דרך בריאותיות, הישגים עם קונפטי
- כפתור "יש לי חשק": תרגיל נשימה ומשימות הסחה
- הנתונים נשמרים רק בדפדפן (localStorage)

להפעלה: לפתוח את `index.html` בדפדפן.

## התקנה בטלפון (כמו אפליקציה)

קודם כל צריך שהאתר יהיה באוויר. מספיק לעשות את זה פעם אחת:
- **GitHub Pages:** ב-GitHub נכנסים ל-Settings, אחר כך Pages, ובוחרים Branch. אחרי כמה דקות מקבלים קישור. אם הריפו פרטי, זה עובד רק עם חשבון בתשלום.
- **Netlify Drop:** נכנסים ל-https://app.netlify.com/drop וגוררים לשם את התיקייה. מקבלים קישור מיד, בחינם.

**אייפון:** פותחים את הקישור ב-**Safari** (לא בכרום). לוחצים על כפתור השיתוף (ריבוע עם חץ למעלה), בוחרים **"הוספה למסך הבית"** ואז **"הוסף"**.

**אנדרואיד:** פותחים את הקישור ב-**Chrome**. לוחצים על ⋮ למעלה ובוחרים **"התקנת אפליקציה"** (או "הוספה למסך הבית").

אחרי ההתקנה יש אייקון של נקי-צ׳אן במסך הבית. האפליקציה נפתחת במסך מלא בלי שורת כתובת, ועובדת גם בלי אינטרנט.
